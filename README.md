API เล็กๆ ด้วย Bun: ลายเซ็น request (Ed25519), ข้อความเข้ารหัส, CRUD หนังสือ. ใช้ SQLite.

**ติดตั้ง**

```bash
bun install
```

**รันเซิร์ฟเวอร์**

```bash
bun build
# ตามด้วย
bun start
# หรือ watch mode
bun run dev
```

**รัน demo (ต้องเปิดเซิร์ฟเวอร์ก่อน)**

```bash
bun run demo
```

**เทสต์**

```bash
bun run test
```
